## О проекте

**Engineers Labs** — рабочее пространство для инженерных экспериментов: от аналитики данных и ML-моделей до автоматизации и прототипов. Каждая "лаборатория" — самостоятельный мини-проект со своим README, зависимостями и точкой входа.

Идея простая: **не бояться пробовать**, фиксировать результат и двигаться дальше.

## Быстрый старт

```bash
# клонировать репозиторий
git clone <ссылка-на-репозиторий>
cd engineers-labs

# перейти в нужную лабораторию
cd apartment-price-prediction

# установить зависимости
pip install -r requirements.txt

# запустить
python main.py
```
