# Robotics & Electronics Projects

Здесь находятся мои проекты в области робототехники и электроники.

Основные направления:
- Arduino
- ESP32
- Работа с датчиками и модулями
- Электрические схемы
- Управление роботами
- Эксперименты с микроконтроллерами

В этой папке я собираю проекты, связанные с созданием устройств, программированием контроллеров и изучением аппаратной части.
