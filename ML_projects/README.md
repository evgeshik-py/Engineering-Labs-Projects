# ML Projects
 
Репозиторий с учебными проектами по машинному обучению. Каждый проект — отдельная папка со своим кодом, данными и README.
 
## Проекты
 
### 1. Apartment Price Prediction
Предсказание цены квартиры на основе линейной регрессии (площадь, расстояние до метро, расстояние до центра, количество комнат).
 
- Стек: `pandas`, `scikit-learn`, `numpy`
- Запуск: `python main.py`
*(добавляйте новые проекты сюда по мере появления)*
 
## Общие принципы проекта
 
- Каждый проект самодостаточен: свой `requirements.txt`, свой `README.md` с описанием запуска.
- Данные (`*.csv`) не всегда попадают в git — см. `.gitignore` внутри каждого проекта.
- Общий `.gitignore` на уровне репозитория:
```
__pycache__/
*.pyc
.venv/
.ipynb_checkpoints/
```
 
## Установка (общая)
 
Для конкретного проекта — зайти в его папку и поставить зависимости:
 
```bash
cd apartment-price-prediction
pip install -r requirements.txt
python main.py
```
 
## Технологии
