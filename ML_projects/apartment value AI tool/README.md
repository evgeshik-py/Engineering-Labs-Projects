# Apartment Price Prediction

Простой проект на основе линейной регрессии (`scikit-learn`) для предсказания цены квартиры по нескольким признакам: площадь, расстояние до метро, расстояние до центра, количество комнат.

## Структура проекта

```
.
├── main.py               # точка входа — запускать отсюда
├── model.py               # класс ApartmentValModel (обучение, предсказание, метрики)
├── apartment_data.csv     # обучающие данные
├── requirements.txt       # зависимости
└── README.md
```

## Установка

1. Клонируйте репозиторий или скачайте файлы в одну папку.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

Весь проект запускается одним файлом — **`main.py`**:

```bash
python main.py
```

Отдельно запускать `model.py` не нужно — он используется как модуль и импортируется внутри `main.py`.

## Что делает проект

1. Загружает данные о квартирах из `apartment_data.csv`.
2. Разбивает данные на обучающую и тестовую выборки (`train_test_split`).
3. Обучает модель линейной регрессии на обучающей выборке.
4. Считает метрики качества (MAE, MSE, RMSE, R²) на тестовой выборке.
5. Предсказывает цену для новой квартиры по заданным признакам.

## Признаки (features)

| Колонка | Описание |
|---|---|
| `factor1_sqrt_m` | Площадь квартиры (м²) |
| `factor2_stepfrommetro` | Расстояние до метро |
| `factor3_nearby_to_center` | Расстояние до центра |
| `factor4_rooms` | Количество комнат |
| `predict` | Целевая переменная — цена |

## Требования

- Python 3.9+
- pandas
- scikit-learn
- numpy

## Примечания

- Датасет учебный, всего 7 объектов — метрики качества (MAE/MSE/RMSE) стоит воспринимать как демонстрацию подхода, а не статистически надёжную оценку.
- `random_state=42` зафиксирован для воспроизводимости разбиения train/test.
